# Ridez

## 📚 Description

Ridez is a ride-booking application designed to connect passengers with drivers quickly and efficiently.  
Book a ride, track its progress, and pay all within the app.

## 🔹 Tech Stack

- **Frontend:** React
- **Backend:** Django
- **Database:** PostgreSQL
